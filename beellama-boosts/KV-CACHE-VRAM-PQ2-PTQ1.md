## 산출 근거
- 가중치: PQ2_0 6.70 GiB (파일) / PTQ1_0 5.53 GiB (파일)
- KV 공식: 토큰당 16층 × (K바이트 + V바이트). f16/bf16=2048B, q8_0=1088B, q4_0=576B, q5_0=704B (각 1024 dim 기준)
- f16 8192셀 실측 512MiB와 일치 확인 (62.5KB/토큰)
- 고정 오버헤드 (recurrent state + compute 버퍼) 약 1.5GB 별도

## 요약
- PQ2가 pp·tg 전부 약 27~30% 빠름. PTQ 장점은 총합 약 1.2GB 절약뿐.
- q5_0-V와 f16/quant 혼합은 포맷 불문 붕괴. 실사용 선택지는 위 6종.
- 실서버 전체 점유 (rocm-smi 실측 2026-09-22, q4_0/q4_0 ctx 131072):
  가중치+KV (표) + 고정오버헤드 ~1.5 + mmproj-BF16 0.87 = PTQ1_0 ~10.3 GiB /
  PQ2_0 ~11.3 GiB. 표의 "총합"은 가중치+KV만이라 rocm-smi 수치(10~11 GiB)와
  직접 비교하면 1.5+0.87 차이로 보일 수 있음.
